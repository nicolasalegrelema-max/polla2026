# Polla Familiar Mundial 2026 - Dashboard V2

Versión adaptada a las hojas actuales del Google Sheets.

## Cómo subir esta versión a GitHub

1. Entra al repositorio `polla2026`.
2. Clic en `Add file` > `Upload files`.
3. Sube y reemplaza estos archivos:
   - index.html
   - styles.css
   - script.js
   - config.js
   - README.md
4. Clic en `Commit changes`.
5. Espera 1 minuto y recarga: https://nicolasalegrelema-max.github.io/polla2026/

## Fuente de datos

Los links CSV ya están configurados en `config.js`:
- Ranking
- Resultados
- Puntajes
- Puntajes Bonus
